# 旗舰参数库 · phone-params

近五年 213 款手机参数对比站（GitHub Pages）

## 在线访问

> **https://yishen510.github.io/phone-params/**

## 项目简介

- 收录近五年（2021–2026）11 大品牌 213 款机型，覆盖 24 项参数（处理器 / 屏幕 / 电池 / 快充 / 影像 / 机身 / 防护等）
- 支持多机型对比、最优值自动高亮、数据可视化图表（ECharts）、Apple 风格滚动动效（GSAP + Lenis）
- 纯前端单页应用，数据外链托管，HTML/CSS/JS 原生实现，无框架依赖
